# bbtf-web-araci

İstanbul Üniversitesi Bilgisayar ve Bilişim Teknolojileri Fakültesi web sitesi (bilgisayar.istanbul.edu.tr) için yayın araçları, kadro kütüphanesi, CMS notları ve içerik envanteri.

| Klasör | İçerik |
|---|---|
| `arac/` | BBTF Yayın Afişi aracı (tek dosya HTML, kaynak ve derleme betiği) |
| `kilavuz/` | Yayın kılavuzu ve web birimine teknik not |
| `kadro/` | Kadro kütüphanesi: kadro.json, kadro.js (fotoğraflar gömülü), foto/ |
| `cms/` | CMS form notları ve ZIP paketinden yayın akışı |
| `envanter/` | Haber, duyuru, öğrenci duyurusu, etkinlik ve manşet envanteri, kapak görselleri |
| `skill/yayinla/` | Bir ZIP paketini seçilen sitede yayımlayan Claude Code skill'i |
| `evidence/` | Test sitesindeki deneme kanıtları |

Durum ve açık işler için `RAPOR.md`, plan için `PLAN.md`.
